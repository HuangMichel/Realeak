REALEAK - DATA LAYER IN ACTION

For fashion brands losing money on products nobody wants, Realeak is an AI agent that reads Vinted every day and flags what's resold brand new, so the next reorder is right.

WHAT DATA
- Brand catalog: the brand's public Shopify feed (products.json). Cabaia: 2,038 products, photos, price, product family.
- Vinted listings: fetched live through the Keenable API. For each listing: title, condition, price, photo, country, first seen / last seen. No seller identity is stored.
- Human answers: corrections typed in the Teach screen of the app.

WHERE IT LIVES (Aiven for PostgreSQL)
- products : the brand catalog
- listings : every Vinted listing seen, with first_seen / last_seen
- matches  : for each listing, its product family, the exact catalog product (or "unknown"), confidence and reasoning
- memory   : what the agent learned (title aliases, confirmed listing photos, human corrections)
- labels   : human answers from the Teach screen
- runs     : every agent run with its live log, duration, cost and written insights

HOW IT FLOWS
Refresh -> Keenable fetches Vinted -> listings stored in PostgreSQL -> the agent identifies each photo with OpenAI vision and writes matches + memory -> the dashboard on Aiven Runtime reads the tables

NUMBERS (22 Oct 2026)
- Live collection: 1,101 Cabaia listings on Vinted (FR, DE, IT, ES, NL, BE), 25 pages fetched in parallel through Keenable in about 1 minute.
- 611 of them are brand new (55.5%), 316 still with their tags (28.7%).
- Agent run on the first 315 listings: 8.7 minutes, $0.29 (about $0.001 per listing) via the OpenAI API.
